# Camino PR Hub demo

The public demo of Camino's purchase request system, served at https://hub.camino.ngo.

Everything in it is made up: the people, projects, suppliers, amounts and bank lines. It runs entirely in the
browser and keeps your changes there; nothing reaches SharePoint or email.

These files are built from the private camino-pr-hub repository with `npm run demo:build:public`
and copied here unchanged. Edit the source there, not here.
